# 分流助手 0.2.4（桌面预览版）

修复分流启用后每隔约 3 秒出现的界面闪动。例行后台维护期间，概览按钮和底栏保持稳定。检查结果有变化时才刷新列表，维护异常仍会显示提示。

## 更新

从旧助手的托盘菜单退出并还原代理，再用 0.2.4 安装包覆盖原目录。原路径安装可继续使用现有本机设置、规则和 VPN 的 helper 排除项。详见[更新指南](../README.md#从-02x-更新)。

## 验证与下载

129 项 .NET 自动化测试通过，包含后台维护与检查列表的回归测试。详见[验证记录](../verification/QA-v0.2.4.md)。
