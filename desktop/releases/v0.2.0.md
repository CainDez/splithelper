# 分流助手 0.2.0（桌面预览版）

- 内置主内核、规则库和直连 helper，配置准备、组件启停及系统代理统一由助手管理，无需 Clash Verge。
- Windscribe 改为直接绑定 IKEv2 / WireGuard 接口，不再需要 Proxy Gateway、网关地址或密码。无其他设备使用时，可以关闭旧代理网关。
- 启用期间自动恢复 Windscribe 连接和自有主内核，识别接口变化后重载配置；保留用户选择的节点和协议。
- 分别备份、接管和还原默认连接及 IKEv2 拨号代理，检测 PAC、Clash 代理守卫及外部代理变更，避免多个程序争抢代理设置。
- 从已确认的旧助手活动配置迁移规则并保存独立快照；保留规则顺序，移除不再适用的旧网关进程例外。
- 同步安装、升级、代理网关关闭和自动启动说明，将旧脚本/Clash 设置移入独立文档。

## 升级

先在旧助手停止分流并从托盘退出，保留旧 Clash 配置和本机数据，再运行安装包覆盖原目录。关闭 Clash Verge 的系统代理、PAC、代理守卫；Windscribe 保持连接和 helper 排除，关闭不再使用的代理网关。打开新版并“一键启用”，按需保存自动启动偏好。详见[安装与升级指南](../README.md)。

已安装并验收本次 0.2.0 本地构建的用户可以继续使用；发布整理没有改变已验收的程序逻辑。

## 验证与范围

Debug / Release 各 90 项自动化测试通过；已完成 Windscribe IKEv2 / WireGuard 隔离断线与恢复验证。本机安装后，Chrome 1080p B 站视频实际连接走 ChinaDirect，海外页面走 VPN；退出还原和重开自动启用通过。完整范围见[验证记录](../verification/QA-v0.2.0.md)。

Windows 10/11 x64 自包含预览版，安装包未签名。仅覆盖遵循 Windows 系统代理的 HTTP/HTTPS/TCP 流量；TUN 和 IPv6 关闭。本轮未覆盖全新机器安装、实际卸载、Windows 重启登录、网络切换/休眠、Mullvad 动态复测、UDP 或其他 Windscribe 协议。

附件提供安装 EXE、便携 ZIP、SHA-256 校验文件及对应第三方源码归档；完整许可证与组件来源也包含在程序包内。
