# 分流助手 0.2.2（桌面预览版）

修复 Windscribe IKEv2 客户端完全退出并重开后，分流助手可能无法启用分流、也无法从托盘退出的问题。

Windscribe 退出时可能临时移除 Windows 的 IKEv2 拨号条目。分流助手现在会按还原记录里的连接名检查并还原 Windows 保存的代理，即使拨号条目暂时不可见。如果其他软件改过这条代理且它仍指向助手端口，助手会保留这条设置和还原记录。

## 更新

保持 Windscribe 已连接，在旧助手的托盘菜单选择“退出并还原代理”，再运行 0.2.2 安装包覆盖原目录。原路径安装可沿用之前的 helper 排除项和本机设置。旧版已卡在退出提示时，请先按[更新指南](../README.md#从-02x-更新)处理残留代理。

## 验证与下载

124 项自动化测试通过。使用包含本次修复的候选构建，在 Windows 上完成了 Windscribe IKEv2 完全退出、重连、助手从托盘退出并还原代理，以及重开助手后检查国内和海外访问。详见[验证记录](../verification/QA-v0.2.2.md)。
