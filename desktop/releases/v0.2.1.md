# 分流助手 0.2.1（桌面预览版）

- 新增“设置 → 自定义规则”，通过界面添加、编辑、停用、删除和调整域名规则顺序。
- 支持仅此域名或包含子域名；可选择国内直连、当前 VPN 或拦截，优先于原有规则。
- 接受域名或完整 HTTP/HTTPS 网址，规范化域名并校验重复项，避免把网址参数保存为规则。
- 运行中保存后重载内核并回读核对；草稿与已保存规则分开，原有规则快照保留。
- 重载失败或取消时恢复上次配置；后台恢复和协议切换继续使用已提交规则。
- 兼容规则覆盖健康检查网站的情况，无法完成出口比对时明确显示未验证状态。

规则对新建连接生效，DNS 沿用当前策略；已有连接可能需要重新打开网页或重启浏览器。详细操作见[自定义规则说明](../README.md#自定义规则021)。

## 更新与使用

从 0.2.0 更新时，先停止分流并从托盘退出，再运行安装包覆盖原目录；保留本机数据、helper 排除项和 VPN 设置。打开 0.2.1，在“设置 → 自定义规则”输入域名或网址，选择策略，点击“添加到列表”再“保存并应用”。详见[更新指南](../README.md#从-02x-更新)。

已安装上一轮 0.2.1 本地测试包时，功能与本次发布一致；正式发布包从干净提交重建，来源以标签与包内 `build-info.json` 为准。

## 验证与范围

124 项自动化测试通过；独立 Mihomo 内核和 Windscribe WireGuard 实测覆盖三种策略、规则优先级、启停删除、重启保留、取消及失败回退、中断恢复。另通过 9 项隔离回归检查，确认恢复后的出口状态不误报，组件文件占用时保留仍工作的内核。原生界面编辑、排序、保存与放弃修改通过。完整证据和边界见[本版验证记录](../verification/QA-v0.2.1.md)。

Windows 10/11 x64 自包含预览版，安装包未签名。仅覆盖遵循系统代理的 HTTP/HTTPS/TCP 流量，TUN 和 IPv6 关闭。本轮未替换正在使用的 0.2.0；未进行 0.2.1 安装后联网验收、Mullvad 动态复测、Windows 重启登录或全新机器安装卸载。Mullvad 配置生成与控制接口有自动化覆盖。

附件提供安装 EXE、便携 ZIP、SHA-256 校验文件及对应第三方源码归档；程序包包含完整内核、helper、规则库与许可证，不包含个人规则或运行数据。
