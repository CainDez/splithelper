# 分流助手 0.1.0（桌面预览版）

首个 Windows 桌面版，按选定的深色工作台原型实现。

- 概览与双链路状态、四步连接向导、Mullvad / Windscribe 设置指导。
- 随包提供 Mihomo 直连组件，无需单独下载 helper 或手动配置程序路径。
- 生成完整 Clash 配置及 DNS 扩展，支持 Clash Verge Rev 2.4.7 自动导入并保留原有订阅和备份。
- 真实链路检测、系统代理启停与还原、托盘、登录启动和等待 VPN 就绪后的自动启用。
- 旧版组件识别与迁移、网关凭据 DPAPI 加密保存、脱敏诊断导出。

下载 `SplitHelper-Setup-0.1.0-win-x64.exe` 安装，或完整解压便携 ZIP。自包含 .NET 10，无需另装运行时。第三方许可证与 Mihomo v1.19.33 对应源码已随包提供，`checksums.sha256` 可用于校验。

适用 Windows 10/11 x64。首次设置仍需在官方 VPN 客户端登录；Windscribe 网关和排除项按界面指引完成。自动管理适配 Clash Verge Rev **2.4.7**，导入前需从托盘完全退出 Clash GUI。

已通过 50 项自动化测试、完整生成配置的 Mihomo 解析、隔离 helper SOCKS/HTTP 检查和原生布局检查。本版为预览版，尚未完成干净机器安装卸载、真实 VPN 切换/断网和登录自启的系统验收。安装包未签名。
