# 0.2.2 Windscribe IKEv2 重启验证

2026-11-23，在 Windows x64 上使用 Windscribe 2.25.8（IKEv2）和随包 Mihomo v1.19.33 验证。实机使用包含本次修复的 0.2.1 本地候选构建，正式包从带 0.2.2 版本号的发布提交构建。

| 检查 | 结果 |
|---|---|
| 旧版复现 | WinINet 中仍存在指向助手端口的手动代理，连接名暂时未出现在 RAS 拨号列表时，旧版跳过该设置并删除还原记录 |
| 缺失拨号条目 | 修复版仍能按还原记录中的连接名找到设置，写入并读回接管前的代理，再清理记录 |
| 外部软件改动 | 已改变但仍指向会话端口的代理保持原值，还原记录也保留 |
| 实机重启 Windscribe | 在助手启用期间完全退出 Windscribe 并重开。Windows 拨号事件确认 IKEv2 重连，助手重新接管默认与 VPN 代理 |
| 托盘退出助手 | 助手、主内核与直连组件均退出，默认、IKEv2 与当前有效代理均解除对助手端口的引用，Windscribe 保持在线 |
| 重开助手 | 自动启用分流，国内 HTTPS 请求返回 200，直连组件和海外路径探测通过，出口地址不同 |
| .NET 自动化 | 124 项通过 |

缺失拨号条目和外部改动两项使用隔离的 WinINet 连接名验证。正式安装包的覆盖安装、Mullvad 联网、Windows 重启登录和其他 Windscribe 协议未在本轮实机复测。
